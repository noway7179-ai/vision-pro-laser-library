# Vision Pro Laser Library

A personal library of laser project files collected for the **WeCreat Vision Pro 45W** diode laser — browsable as a visual catalog, flash-sheet style.

## Browse it

**Live catalog:** https://noway7179-ai.github.io/vision-pro-laser-library/

- ~595 projects: cut files (boxes, clocks, toys, kinetic builds, rubber-band guns, book nooks, Star Wars) and engraving plates (public-domain art, photo plates, high-contrast engraving, pop art, wildlife, famous portraits)
- Every card shows a preview, the project type (cut / engrave), license notes, and — where tested starting points exist — Vision Pro settings
- Search and filters: by category, by cut vs. engrave, and personal-use items

## Notes

- Files were collected from free sources (public-domain archives, manufacturer sample clubs, maker sites). Per-file license notes are on each card — several are **personal use only**; check the card before selling anything made from a design.
- v1 note: the catalog and previews live here; the downloadable design files are being linked in a follow-up pass, so download buttons do not resolve yet.

## The machine

WeCreat Vision Pro 45W enclosed diode laser, 500 × 320 mm work area, camera/autofocus, rotary. Settings in the library are sourced starting points — always run a small test first and measure your actual stock thickness.
